Dress Code

One page, dressed three ways. Where you write CSS decides how far it reaches and which rule wins when two disagree.

You will be able to

  • Write the same style as an external file, a <style> block and a style attribute.
  • Predict which of them wins when they set the same property.
  • Choose the right place for a rule, and say what each choice costs.

About 30 minutes

The original exercise

Three files, one look

The first version from the course: a greeting, a photo and a text box, built three times with exactly the same rules. Switch between the files: nothing on the page changes, only where the CSS lives.

Shown as it was made. Open external.html, internal.html or inline.html on their own.

The core idea

Three places to write CSS

The three versions look identical; only where the CSS is written changes. That place decides how far a rule reaches and how hard it is to override.

  • External CSS

    <link rel="stylesheet"
      href="style.css">
    Where
    A separate .css file, linked in the head
    Reach
    Every page that links it
    Specificity
    Normal selector specificity; cached by the browser
    Open external.html

  • Internal CSS

    <style>
  p { color: #1d4ed8; }
</style>
    Where
    A <style> block in the head
    Reach
    This one page
    Specificity
    Same as external; whichever comes later in the document wins a tie
    Open internal.html

  • Inline CSS

    <p style="color: #1d4ed8;">
  Välkommen!
</p>
    Where
    A style attribute on the element
    Reach
    That single element
    Specificity
    Beats any selector in a stylesheet (only !important overrides it)
    Open inline.html

When they compete

  1. An inline style attribute wins over rules in a file or a <style> block.
  2. Between an external and an internal rule with the same specificity, the one that appears later in the document wins: a <style> block after the <link> overrides the file.
  3. In practice: shared look in an external file, page-specific tweaks internal, inline only when there is no other way.

Dress Code

The same page, dressed three ways. A greeting, a photo and a text box, styled with exactly the same rules. The three versions look identical; only where the CSS is written changes.

  • External CSS

    <link rel="stylesheet"
      href="style.css">
    Where
    A separate .css file, linked in the head
    Reach
    Every page that links it
    Specificity
    Normal selector specificity; cached by the browser
    Open external.html

  • Internal CSS

    <style>
  p { color: #1d4ed8; }
</style>
    Where
    A <style> block in the head
    Reach
    This one page
    Specificity
    Same as external; whichever comes later in the document wins a tie
    Open internal.html

  • Inline CSS

    <p style="color: #1d4ed8;">
  Välkommen!
</p>
    Where
    A style attribute on the element
    Reach
    That single element
    Specificity
    Beats any selector in a stylesheet (only !important overrides it)
    Open inline.html

When they compete

  1. An inline style attribute wins over rules in a file or a <style> block.
  2. Between an external and an internal rule with the same specificity, the one that appears later in the document wins: a <style> block after the <link> overrides the file.
  3. In practice: shared look in an external file, page-specific tweaks internal, inline only when there is no other way.

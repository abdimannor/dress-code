# Dress Code

The same HTML content styled three different ways — demonstrating external, internal, and inline CSS side by side.

| File | Method |
|---|---|
| `external.html` | Styles in a separate `.css` file |
| `internal.html` | Styles inside a `<style>` tag in the `<head>` |
| `inline.html` | Styles applied directly on each element |
